# flutter_idenframe

Flutter plugin for **Idenframe**: native identity capture (selfie with liveness + ID document)
for mobile apps. On-device processing, guided UI, and your own backend.

> **Status:** under construction. Not published yet.

## What it does

- Guided selfie capture with active liveness challenges.
- ID document capture (front and back) with on-device quality and text checks.
- Returns a structured evidence package (images, short video, quality signals) to your app, or
  uploads it to your own endpoint.
- No vendor cloud required. No telemetry.
